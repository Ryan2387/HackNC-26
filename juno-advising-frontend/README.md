# Juno Advising frontend

This is the React/Vite frontend demo for Juno Advising.

## Install
1. Extract the ZIP to Desktop or Documents (NOT the Trash).
2. In Terminal, navigate to the extracted `juno-advising-verified` folder.
3. Run `npm install` and `npm run dev`.
4. Open the Local URL printed by Vite.

Run `pwd` before npm commands to verify that your working directory is not inside `.Trash`.

The AI chat expects a separate backend at `/api/chat`; without one it displays a demo fallback message.
